# 📊 Sistema de Análisis de Texto

Aplicación web desarrollada con **ASP.NET Core (.NET 9)** que permite analizar texto introducido por el usuario.  
El análisis se realiza mediante un **script en Python**, ejecutado desde el backend, y los resultados se muestran en un **frontend HTML/JavaScript** servido desde `wwwroot`.

---

## 🛠️ Requisitos previos

Para ejecutar el proyecto es necesario tener instalado:

- Visual Studio 2022 (actualizado)
- .NET SDK 9.0
- Python 3.10 o superior
- Python añadido al PATH del sistema

Comprobación desde consola:

```bash
dotnet --version
python --version
```
